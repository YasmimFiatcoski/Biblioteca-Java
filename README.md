# Sistema de Biblioteca em Java

Projeto de um sistema simples de biblioteca feito em Java.  
Permite consultar livros, verificar se estão disponíveis e emprestar.  

## Como usar

1. Abra o projeto em uma IDE Java (NetBeans, VS Code, Eclipse).  
2. Execute a classe `Biblioteca.java`.  
3. Use os prompts para consultar e emprestar livros.

## Classes

- `Biblioteca.java` — classe principal com o menu de interação.  
- `Livro.java` — representa um livro.  
- `Usuario.java` — representa um usuário da biblioteca.
